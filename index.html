Lake Map Coaster Creator

Search any lake on Earth → export a laser-ready SVG coaster (xTool-friendly)

1 · Lakes

      Search is powered by OpenStreetMap Nominatim (needs internet). Add as many lakes as you like — each gets its own small label.

      2 · Text

      3 · Font

      4 · Layout

      Drag the map to pan · scroll to zoom · drag labels to move them · click a label to edit it.

      Selected label

      5 · Streets

      Best for a single small lake. Streets export as a separate blue line layer — set it to Score in xTool Creative Space (or Engrave for bolder lines). Data © OpenStreetMap via Overpass API.

      6 · Location pins

        Drag a pin onto the home, cabin or memorable spot — the tip marks the location. Load streets first to find the exact place.

        7 · Map extras

        Scale bar, compass, info box, labels and pins are all draggable on the preview.

        8 · Engraving

        Everything black = engrave (fills, no strokes). Red circle = cut layer. All text is converted to vector paths, so it imports into xTool Creative Space with no font issues.
